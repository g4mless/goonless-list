# goonless-list
Blocking the website outright is a bad idea and won't help you break the gooning addiction, but I have a much better solution. It involves blocking the stylesheet (how the website looks) and images on the website, which can be enough to make you think twice about whether or not to open the website after being presented with a page that looks like a mess of HTML and contains only text without any corn images that your brain want.

## Usage
Simply just add this filter list from this url to your favorite adblocker software
```
https://raw.githubusercontent.com/g4mless/goonless-list/refs/heads/main/list.txt
```
works well with uBlock Origin, uBO Lite & Brave Shields.
